# PanoWizard Help

![A complete 360-degree panorama created with PanoWizard](Images/00-finished-panorama.jpg)

Turn one horizontal ring of overlapping fisheye photographs into a complete **360° × 180° panorama**. Inspect the result, guide stitching with masks, repair local details, and export a panorama, an interactive viewer, or a Little Planet.

New to PanoWizard? Start with the [illustrated Getting Started guide](getting-started.html), or choose a topic below.

## Start

- **[Getting Started](getting-started.html)** — Follow a complete project from source photographs to export.
- **[Creating and Opening Projects](projects.html)** — Start, reopen, and save your work.
- **[Adding Source Images](source-images.html)** — Choose a sequence and inspect its images.
- **[File Access / Grant Access](file-access.html)** — Give macOS permission to read external source photographs.

## Create and inspect

- **[Creating the Panorama](creating-panorama.html)** — Analyze and stitch the image sequence.
- **[Preview and Navigation](preview.html)** — Explore the panorama and adjust its overall appearance.

## Correct

- **[Masks](HowTo/Masking/index.html)** — Exclude unwanted source pixels or prefer better overlap.
- **[Retouching](HowTo/ManualPatch/index.html)** — Repair a local area with a manual patch and an image editor.
- **[AI Retouch](HowTo/AIPatch/index.html)** — Mask a local problem, generate a repair, and review it before applying.

## Export

- **[Little Planet](HowTo/LittlePlanet/index.html)** — Shape a square planet image from the panorama.
- **[Export](export.html)** — Save JPEG, PNG, or an interactive HTML viewer.

## Support and privacy

- **[Support](support.html)** — Ask a question or report a problem.
- **[Privacy Policy](privacy.html)** — How PanoWizard handles images, projects, and optional AI retouching.
