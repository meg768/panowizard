# Adding Source Images

For a new project, **Create Your Panorama** on the welcome screen opens the image picker. In an open project, click **Add** in the sidebar to select more images. Use a complete overlapping 360° ring with enough vertical coverage for the full sphere. All images used for stitching must have the same pixel dimensions after rotation.

Select an image to inspect it. When needed, right-click an image in the sidebar and choose **Image Type → Automatic**, **Panorama Ring**, or **Repair Image** to describe its role. A repair image fills local missing coverage rather than adding another panorama row. Use the rotation button to correct an image's orientation without changing the original file.
