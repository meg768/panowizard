# Support

For instructions, start with [PanoWizard Help](index.html). For trouble opening external source images, see [File Access / Grant Access](file-access.html).

## Ask a question or report a problem

Support for PanoWizard is provided by Magnus Egelberg through [GitHub Issues](https://github.com/meg768/panowizard/issues). Search existing issues first, or [open a new issue](https://github.com/meg768/panowizard/issues/new). A GitHub account is required to post.

Please include:

- The Version and Build shown in **PanoWizard → About PanoWizard**.
- Your macOS version.
- What you did, what you expected, and what happened.
- A screenshot or the exact error message, if useful.

Issues are public. Do not post API keys, private photographs, or project files containing sensitive information. A `.pw` project can contain source file paths, panorama images, and retouch patches.

For questions about data handling, see the [Privacy Policy](privacy.html). Do not share personal details in a public issue.
