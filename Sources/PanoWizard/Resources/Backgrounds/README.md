# Uppstartsbilder

Lägg fasta uppstartsbilder för PanoWizards välkomstvy i den här mappen.

- Format: `.jpg`, `.jpeg` eller `.png`
- Rekommenderad storlek: 2500–4000 px bred
- Bilden bör vara liggande och sakna inbakad text eller gränssnitt
- Välj gärna en komposition med lugn yta kring mitten för välkomsttexten

Alla bilder i mappen följer automatiskt med nästa appbygge och deltar i det
slumpmässiga urvalet. Swift-koden behöver inte ändras när en bild läggs till
eller tas bort.
